Головоломка дня

Информация о конфиденциальности для Android-приложения «Головоломка дня» (пакет ru.forestmusic.logicgames).

Кратко

  • Приложение не требует регистрации и не создаёт учётную запись.
  • Игровой прогресс (тренировки, навыки, серия дней, достижения, настройки) хранится локально на устройстве.
  • Собственного сервера пользовательского профиля у приложения нет.

Аналитика

Для понимания того, как пользуются приложением, подключена AppMetrica (Яндекс). Приложение отправляет обезличенные игровые события (например, старт и завершение тренировки, использование подсказки, события рекламы) без сырых ответов на задачи и без данных профиля, которые позволяли бы вас идентифицировать как человека.

Подробности обработки данных SDK см. в актуальной документации AppMetrica / Яндекса.

Реклама

В приложении используется Yandex Mobile Ads для показа баннеров, межстраничной и вознаграждённой рекламы. Сторонний SDK может обрабатывать технические данные, необходимые для показа и измерения рекламы.

Основной игровой функционал доступен без сети; реклама не является условием прохождения ежедневной тренировки.

Сторонние SDK

AppMetrica и Yandex Mobile Ads могут получать технические данные устройства и сети в соответствии со своими политиками. Мы не передаём в аналитику ответы на головоломки, семена генерации и адрес электронной почты пользователя через игровой код приложения.
